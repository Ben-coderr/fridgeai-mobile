# Submission Checklist

Submit once, by **17:30 Tunis time**, through the official Google Form — pushing code to GitHub does not submit your project.

## Three required links

- [ ] **Source code URL** — this repo's GitHub link. Make sure it's accessible (public, or a reviewer account invited if private).
- [ ] **Presentation URL** — Google Slides (shared "anyone with the link can view") or a PDF hosted on Drive.
- [ ] **90-second demo video URL** — unlisted YouTube link (preferred) or an accessible Drive link. Test it in a private/incognito window first.

## Project details to have ready

- [ ] Team name (same as your Final Team Confirmation) and lead email
- [ ] Country, confirmed space or "ONLINE"
- [ ] Team lead + every member's full name
- [ ] Project title
- [ ] Summary, **max 150 words** (see `pitch-outline.md` for a template)
- [ ] Problem, solution, key features, technologies used, next step
- [ ] Prize selections: one primary prize + any additional eligible partner awards, or "Country podium only"
- [ ] For each selected award: 2–3 sentences of evidence of fit
- [ ] AI/tool disclosure: which models/APIs/datasets you used, for which stage, your access constraints, and whether Brev was used (state clearly if not)

## Final checks (do these at the 15:30 checkpoint, not at 17:25)

- [ ] Open the repo link in a private browser window — does it load without your login?
- [ ] Open the slides link the same way.
- [ ] Open the video link the same way, and confirm it plays and is exactly ~90 seconds.
- [ ] README in the repo has clear setup/run instructions (already true for `backend/` and `mobile/`).
- [ ] No real API keys committed anywhere (`git log -p | grep -i api_key` if in doubt).
